# Code of Conduct

This project is a place to build a tool together. Everyone who takes part in its issues, pull requests and
discussions is expected to keep it a good place for others.

## What is expected

- Be respectful. Disagree with the idea, the code or the measurement, not with the person.
- Assume good intent, and ask before assuming.
- Be concrete: a small example, the command you ran and the output you got help everyone more than an opinion.
- Welcome newcomers. Clojure, static analysis and MCP are each a lot to learn; nobody starts knowing all three.
- Accept that a maintainer may say no, and that "not now" is an answer.

## What is not acceptable

- Insults, personal attacks, harassment, and sexual or discriminatory language or imagery.
- Publishing someone's private information.
- Sustained disruption of a thread after being asked to stop.

## If something goes wrong

Tell the maintainer, Barış Can Ateş, through his [GitHub profile](https://github.com/Bariscanates404), or use
GitHub's report function on the comment. Reports are handled in private. The maintainer may edit or remove
comments, close threads, and block accounts from the repository when this code is not followed.
